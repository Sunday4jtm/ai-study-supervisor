# AI 学习监督员

> 本地优先的 AI 学习助手：导入自己的笔记，用 RAG 答疑、Agent 出题、LLM 批改，配错题本与间隔复习。
> **本仓库只发布安装包与更新日志，源代码不公开。**

---

## 这是什么

一个跑在你电脑上的学习工具。你把课程笔记 / 面试题 / 技术文档导进去，它会：

- **笔记问答**：基于你的笔记回答，答案带来源引用，可追问
- **出题与批改**：按知识点或题库出题（选择 / 判断 / 填空 / 简答），客观题自动判分，简答题给评分要点
- **错题本 + 间隔复习**：答错自动入库，按遗忘曲线提醒重练
- **学习状态**：连胜、正确率、薄弱知识点、自评失准率
- **桌宠**：一个会在你学习时待机、出错时安慰你的小助手（可关闭）

数据全部存在本机，不上传任何服务器；只有调用大模型时才会把你的问题与相关笔记片段发给你自己配置的模型服务商。

## 安装与首次使用

### Windows

1. 双击 `AI学习监督员_x.y.z_x64-setup.exe`
2. 若弹出「Windows 已保护你的电脑」→ **更多信息** → **仍要运行**（未购买代码签名证书，不是病毒）
3. 启动后**先等 10~30 秒**：后端在解压预热，此时页面空白是正常的
4. 左侧 **设置**：
   - 供应商接口地址：`https://open.bigmodel.cn/api/paas/v4/`
   - API Key：填你自己的（[智谱开放平台](https://bigmodel.cn) 注册后创建）
   - 点 **保存并重启后端**
5. 左侧 **知识库** → 导入你的笔记（PDF / Word / TXT / Markdown / CSV）
6. 回到 **笔记问答** 开始提问

### macOS

1. 打开 DMG，把 App 拖进「应用程序」
2. 第一次打开：**右键 → 打开** → 再点「打开」（未签名，双击会被 Gatekeeper 拦住）
3. 后续步骤同 Windows（4~6 步）

## 系统要求

- **Windows**：Windows 10 1803+ / Windows 11，需要 WebView2（Win11 自带；Win10 若缺失，安装器会引导安装）
- **macOS**：macOS 13.1+，Apple Silicon（M 系列）
- **磁盘**：约 1.2 GB（含本地向量模型）
- **网络**：调用大模型时需要联网；笔记检索本身是离线的

## 你的数据在哪

| 平台 | 位置 |
|---|---|
| Windows | `%APPDATA%` 下的本应用数据目录 |
| macOS | `~/Library/Application Support/` 下的本应用数据目录 |

> 完整路径可在「设置 → 诊断信息」里查看，也可以直接复制给作者用于排障。

- 笔记原文、向量库、错题本、学习记录都在这里，**删掉目录等于清空全部数据**
- API Key 存在系统凭据管理器（Windows Credential Manager / macOS 钥匙串），不落明文
- 目录权限收紧到 0700（仅当前用户可读）

## 常见问题

**Q：为什么 Windows 说"未知发布者"？**
没有购买代码签名证书（个人项目），属正常现象。校验方式：对照 Releases 说明里的 SHA-256。

**Q：启动后页面一直空白？**
后端还在预热（首次 10~30 秒）。超过 1 分钟仍空白 → 看设置页的日志路径，把 `sidecar.log` 发作者。

**Q：问答没反应 / 一直转圈？**
① 设置页确认 Key 已保存且模型可用；② 知识库是否已导入笔记（空知识库会直接拦下问答）。

**Q：能离线用吗？**
笔记检索是离线的，但问答/出题/批改都要调大模型，需要联网与 API Key。
